# 0004: 在评测中采用声明级人工批准替代证据

状态：accepted
日期：2026-08-11

## 背景

严格检索评分原先要求每个预期证据只命中一个规范 passage。Issue #56 的 `ARF-026` 真实运行
检索并引用了分别支持 ReAct 环境动作和 Self-RAG critique token 的 passage，但因为它们不是
数据集中唯一记录的摘录，检索和引用仍被判为失败。直接接受同页 chunk 或语义相似文本会把
人工判断隐式交给评测器，削弱 SourceTrace 的可重放性与严格证据约束。

## 决定

1. `expected.evidence` 中每个元素代表一个独立声明，并可使用稳定 `claim_id` 标识。
2. 规范 passage 保持唯一且优先；人工审核后可为该声明添加有序的
   `approved_alternatives`。
3. 每个 passage 仍同时精确匹配不可变文档版本、PDF 页码和摘录子串。替代项不能跨声明共享，
   同页其他 chunk、主题相似文本和未审核候选继续失败。
4. 一个统一的纯计算匹配模块供离线 Harness、真实检索、reranker 和失败诊断复用。报告分别
   保存每个声明的 `canonical`、`approved_alternative` 或 `not_matched` 结果。
5. 新增替代项必须提升数据集版本并更新人工审核时间；既有不含 `claim_id` 和替代项的数据集
   继续按证据顺序生成稳定诊断标识并保持原评分语义。

## 替代方案

1. 只保留单一规范摘录：会把真实支持同一声明的 passage 误报为检索失败。
2. 接受相同文档和页码的任意 chunk：无法证明文本支持声明，违反严格证据约束。
3. 使用 embedding 或大模型判断语义等价：结果不可完全确定性重放，还会把评测标签泄漏到
   模型判断链路。
4. 为整题维护共享替代证据池：一个 passage 可能错误满足题内其他声明。

## 后果

- 数据集审核者必须明确替代 passage 所属声明，并审核其文档版本、页码和摘录。
- Report 和检索诊断增加逐声明匹配轨迹，但在线检索、Top K、门禁、引用和拒答规则不变。
- `ARF-026` 可在不硬编码答案或修改模型提示词的情况下区分真实检索缺失与已批准替代命中。
