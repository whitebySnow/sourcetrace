# 0007: 为额外槽位的通道首位增加有界 reranker 分歧保护

状态：accepted
日期：2026-08-17

## 背景

额外槽位的通道融合首位可能包含 dense 与 lexical 共同支持的候选，但 cross-encoder 会将它
降到 reranker 排名靠后的位置。无条件以该候选替换 reranker 第二名会保留部分被错排的候选，
也可能挤掉 reranker 第二名的必要证据。

现有 `4/2/2` 分配是为额外槽位保留两个覆盖位置，不增加最终 Top-8、候选池或查询预算。
需要在不读取评测期望、case ID 或文档正文的前提下，区分可接受的排序分歧与严重降级。

## 决定

额外槽位仍先保留 reranker 第一名。第二个覆盖位置默认保留 reranker 第二名；仅当通道融合
首位的逐查询 reranker 排名不超过最终 Top-K 加上两个额外槽位的最大覆盖数时，才以该通道首位
替换第二名。默认 Top-8 且最多两个额外槽位时，该界限为第 12 名。

原始问题继续仅按 reranker 排名获取其最多四个覆盖候选。通道首位已经是 reranker 第一名时，
该规则不改变选择。候选在窗口之外时保留 reranker 前两名。

## 替代方案

1. 无条件保留通道融合首位：会使严重降级候选挤掉 reranker 第二名。
2. 只按 reranker 排名选择：无法保留有限窗口内的通道排序分歧。
3. 增加 Top-8 或每槽覆盖配额：扩大上下文和成本，且改变已验证的容量边界。
4. 读取评测真值、case ID 或文本内容：会把离线评测信息泄露到线上选择逻辑。

## 后果

- 选择器只使用已有的通道融合排名、逐查询 reranker 排名和配置的最终 Top-K。
- `4/2/2` 覆盖配额、候选池、页面邻居、最低 cosine 与 Evidence/Citation/Refusal 门禁不变。
- 检索配置版本必须升级，并在版本化 30 题本地差异回放中证明零回归后才可接受本 ADR。
