# Triage Labels

The engineering skills use five canonical triage roles. This table maps each role to the GitHub
label used by this repository.

| Canonical role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer needs to evaluate the issue |
| `needs-info` | `needs-info` | More information is required from the reporter |
| `ready-for-agent` | `ready-for-agent` | The issue is fully specified and ready for an agent |
| `ready-for-human` | `ready-for-human` | The issue requires human implementation or judgment |
| `wontfix` | `wontfix` | The issue will not be actioned |

When a skill refers to a canonical triage role, use the corresponding GitHub label from this
table. Update the GitHub label column if the repository vocabulary changes.
